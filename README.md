# Time Rewind（時間巻き戻しMOD） — Minecraft Forge 1.20.1

ダメージを受けた瞬間、そのダメージを打ち消して **3秒前** に戻ります。
プレイヤーだけでなく、周囲のブロック・モブ・ドロップアイテムも同じ時刻へ巻き戻ります。

## ビルド

必要なもの: JDK 17

```bash
./gradlew build          # Windows は gradlew.bat build
```

`build/libs/timerewind-1.0.0.jar` を `.minecraft/mods` に入れます（クライアント・サーバー両方）。
開発環境で試すなら `./gradlew runClient`。

> Forge のバージョンは `gradle.properties` の `forge_version=47.3.0` で指定しています。
> 手元の 1.20.1 Forge に合わせて 47.x の任意の版に変えて構いません。

## 何が巻き戻るか

| 対象 | 内容 |
|---|---|
| プレイヤー | 位置・ディメンション・向き（頭含む）・速度・落下距離・エリトラ飛行 |
| | 体力・衝撃吸収・満腹度・隠し満腹度・燃焼・空気・凍結・ポーション効果 |
| | インベントリ・選択スロット・経験値（設定でOFF可） |
| ブロック | 半径16ブロック内のあらゆる変更（採掘・設置・爆発・火・水流・ピストン・エンダーマン等） |
| | チェスト等の中身（右クリックで開く直前の内容を記録） |
| エンティティ | 生きているモブ・アイテム等の位置・体力・速度 |
| | 3秒以内に死んだ／消えたモブ・アイテムは復活 |
| | 3秒以内に出現したもの（ドロップ品・矢・湧いたモブ・点火TNT）は消滅 |

点火済みTNTや爆発したクリーパーも3秒前の状態で戻るので、「爆発を見てから逃げ直す」遊び方ができます。

## しくみ

1. **毎tick記録** — tick終了時にプレイヤーの状態をリングバッファ（3秒＝61件）へ保存。周囲のエンティティも同時に軽量スナップショットを保存。
2. **ブロック変更の記録** — Mixin で `Level#setBlock` の先頭に割り込み、プレイヤー周辺で起きた変更の「変更前の状態」（＋ブロックエンティティNBT）を記録。
3. **ダメージ検知** — `LivingDamageEvent`（防具計算後の最終ダメージ）をキャンセルし、巻き戻しを「予約」。
4. **tick終了時に実行** — 爆発処理の途中などでワールドを書き換えないよう、まとめて実行：
   ブロック復元 → エンティティ復元 → プレイヤー復元 → 演出（逆ポータルの軌跡・効果音・アクションバー表示）。
5. **クールダウン** — 巻き戻し後3秒間は通常どおりダメージを受けます（無限ループ防止）。

アイテム複製対策として、巻き戻し中にこぼれたアイテム・経験値は出現させず、置き換えるブロックの中身は先に空にしています。

## 設定 `config/timerewind-common.toml`

| キー | 既定 | 説明 |
|---|---|---|
| `trigger.enabled` | true | 全体のON/OFF |
| `trigger.rewindSeconds` | 3.0 | 戻る秒数 |
| `trigger.cooldownSeconds` | 3.0 | 巻き戻し後のクールダウン（rewindSeconds未満にはならない） |
| `trigger.minDamage` | 0.0 | 発動する最小ダメージ（防具計算後） |
| `trigger.lethalOnly` | false | 致死ダメージのときだけ発動 |
| `trigger.excludedDamageTypes` | `["minecraft:generic_kill"]` | 発動しないダメージ種別（/kill など） |
| `rewind.inventory` | true | インベントリ・経験値も戻す |
| `rewind.blocks` | true | ブロックを戻す |
| `rewind.entities` | true | エンティティを戻す |
| `rewind.radius` | 16 | ワールドを記録・復元する半径 |
| `rewind.maxBlockChanges` | 200000 | ブロック変更記録の上限（ディメンションごと） |

## コマンド

- `/timerewind toggle` — 自分だけON/OFF（サーバー再起動でリセット）
- `/timerewind status` — 記録量・クールダウン残りを表示
- `/timerewind trigger [player]` — 今すぐ巻き戻す（OP権限、クールダウン無視）

## 動作確認の手順

1. サバイバルで草ブロックを数個掘る → 3秒以内に高所から落ちる → 掘った位置・ブロック・インベントリが戻るか
2. ゾンビを倒した直後に被弾 → ゾンビが復活し、ドロップ品が消えるか
3. TNTに点火して爆発に巻き込まれる → 地形が戻り、TNTが点火状態で戻るか
4. チェストから中身を取り出し、直後に被弾 → チェストとインベントリの両方が元に戻るか（複製されない）
5. ネザーポータル通過直後に被弾 → 元のディメンションへ戻るか

クリエイティブ・スペクテイターでは発動しません。

## 既知の制限

- **マルチプレイ**: ワールド巻き戻しは被弾したプレイヤーの周囲だけですが、近くにいる他プレイヤーの作業（設置したブロック等）も一緒に戻ります。他プレイヤー自身の位置・持ち物は戻りません。
- チェスト等の中身は「プレイヤーが右クリックした時点」と「ブロック変更時」のみ記録。ホッパーによる自動搬送は戻りません。
- モブのAI状態（ターゲット等）、額縁の中身の回転、トロッコ付きチェストの中身は戻りません。
- 刺さっている矢など生存中の飛翔体は位置を戻しません（3秒以内に放たれた矢は消えます）。
- エンティティの完全なNBTは「消滅した瞬間」に保存するため、消える直前に名前を付けた等の変化はそのまま残ります。

```
  TimeRewindMod.java          エントリーポイント
  Config.java                 設定
  core/RewindManager.java     記録と巻き戻しの本体
  core/PlayerSnapshot.java    プレイヤー状態の保存・復元

  event/ForgeEvents.java      Forgeイベントの受け口
  command/RewindCommand.java  /timerewind
  mixin/LevelMixin.java       ブロック変更のフック
```
